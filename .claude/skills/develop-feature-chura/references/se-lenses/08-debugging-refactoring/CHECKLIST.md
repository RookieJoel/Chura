# Debugging and Refactoring Checklist

Use this checklist as a quick review guide.

- [ ] Reproduction
- [ ] Evidence gathering
- [ ] Hypothesis testing
- [ ] Root cause analysis
- [ ] Minimal fix
- [ ] Regression tests
- [ ] Behavior-preserving refactoring

## Final validation

- [ ] Scope is clear
- [ ] Assumptions are stated
- [ ] Risks are identified
- [ ] Recommendations are actionable
- [ ] Verification method is defined
