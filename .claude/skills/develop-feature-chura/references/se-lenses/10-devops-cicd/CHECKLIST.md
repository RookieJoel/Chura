# DevOps and CI/CD Checklist

Use this checklist as a quick review guide.

- [ ] CI pipeline
- [ ] Build / test / lint automation
- [ ] Docker
- [ ] Secrets in pipelines
- [ ] Deployment strategy
- [ ] Rollback
- [ ] Release observability

## Final validation

- [ ] Scope is clear
- [ ] Assumptions are stated
- [ ] Risks are identified
- [ ] Recommendations are actionable
- [ ] Verification method is defined
